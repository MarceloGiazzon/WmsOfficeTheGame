Papeis por Usuario

Tela dedicada para atribuir/remover papeis (identity_roles) de um usuario (identity_users), cobrindo o fluxo "aqui esta a Alice, aqui estao seus papeis" que a tela generica de CRUD do UserRole nao oferece (ela so cria uma linha por vez, escolhendo IDs crus). Um papel so passa a valer no proximo login desse usuario (os papeis sao lidos e gravados no JWT no momento do login).
